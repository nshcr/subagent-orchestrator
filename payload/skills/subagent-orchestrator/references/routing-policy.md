# Routing Policy

Use the smallest route that can finish the acceptance anchor. Every child is a leaf;
the primary is the only coordinator and decision owner.

## Role admission

| Need | Route | Admit only when |
|---|---|---|
| One narrow read-only codebase question | built-in `explorer` | Its focused scan replaces material primary exploration |
| One settled implementation slice | built-in `worker` | Strategy, exact ownership, and acceptance are already known |
| Structured test or bounded log evidence | `evidence_tester` | One noisy surface can be isolated behind exact acceptance fields and one artifact |
| One unresolved execution/state/persistence boundary | `boundary_mapper` | A targeted primary check was insufficient and no design verdict is requested |
| Independent high-risk invariant | fresh `risk_reviewer` | Writers are terminal, the candidate is frozen, and the invariant is exact |
| Evidence-qualified irreversible ambiguity | `risk_reviewer_max` | A valid reviewer escalation names competing explanations and the affected decision |
| Simple, strategic, ambiguous, ordered, or shared-state work | primary | Delegation would add coordination or prematurely split reasoning |

Roles are not substitutes. `evidence_tester` does not edit source or diagnose beyond
evidence. `boundary_mapper` traces one boundary but does not decide the defect or design.
Reviewers do not explore, implement, invent requirements, or own the repair. A reviewer
may actively seek a falsifying path only inside its named invariants.

## Valid transitions

- `explorer` or `boundary_mapper` returns evidence to the primary; only the primary may
  settle strategy before a `worker` receives a write slice.
- A `worker` returns a terminal receipt; the primary samples, integrates, and runs direct
  checks before any tester or reviewer sees the result.
- Use `evidence_tester` only when raw test/log volume would pollute the primary context;
  ordinary targeted checks stay with the primary.
- A review BLOCK returns findings to the primary for independent adjudication. It never
  transfers design ownership to the reviewer or automatically authorizes a worker.
- `risk_reviewer_max` follows only a valid indeterminate reviewer result; PASS or BLOCK
  never routes to it.

## Topology and expansion

- Start one child. Add a second ordinary first-wave child only for bounded, independent,
  ownership-safe work with an expected wall-time or context benefit. Never split one
  ordered reasoning chain, shared mutable state, or one slow external operation. Keep
  the ordinary cap at two children and one active writer with no overlapping write scope.
- A later wave, another writer, nested delegation, scope expansion, or reviewer rerun
  opens the Skill's expansion checkpoint. Current required children must be terminal and
  integrated first. The primary may clear one bounded next child when new evidence,
  unchanged material scope/risk, and displaced work justify it; otherwise work directly.
- Ask when the user requested a checkpoint or at a material user-owned boundary. Expansion
  itself is not a question. If the choice changes outcome, acceptance, external behavior,
  compatibility, security, privacy, architecture, meaningful cost, migration, or
  irreversible effect, ask early with one recommended default. Operational blockers are
  reported, not offered as choices.
- Use fresh context and English receipts. Keep the primary model and effort user-controlled.
  Installed child settings are fixed: built-ins and `boundary_mapper` use Sol/high,
  `evidence_tester` uses Luna/max, `risk_reviewer` Sol/xhigh, and `risk_reviewer_max` Sol/max.

## Review routing

- One fresh `risk_reviewer` is the normal independent gate. Multi-review exists only for
  an explicit user request: one final batch of at most three fresh reviewers, disjoint
  invariants, one frozen candidate, no voting, and no follow-on design workshop.
- After a repair and fresh recheck still BLOCK, the primary adjudicates from first
  principles. It may reject an unsupported finding, repair directly, or identify a real
  blocker. Another independent review is a new expansion checkpoint and requires a
  changed candidate or new discriminating evidence.
- Unchanged uncertainty after two decision-directed attempts is an evidence plateau.
  Stop variants and secure the smallest observation that distinguishes the remaining
  hypotheses. Never use another child merely to seek confidence.

## Closure

Child terminal state, a gate line, or exhausted budget closes only transferred work.
Close the task against the original outcome and proportionate claim-matched evidence.
Do not build supporting machinery before the smallest real task proves the core behavior.

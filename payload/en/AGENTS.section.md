## Subagents and parallelism

- Default to one agent. Use `$subagent-orchestrator` only when the user requests delegation, a bounded leaf replaces material primary work or isolates noisy evidence, or an independent high-risk gate is required. Keep small, sequential, ambiguous, shared-state, and coordination-heavy work with the primary.
- The primary retains authorization, scope, integration, finding adjudication, and final acceptance. Children are leaves: start one, add a second ordinary child only for bounded independent ownership-safe work, keep at most one active writer with no overlapping write scopes, and use installed model and effort settings. Read the Skill for role selection, handoffs, later waves, reviews, and evidence-based closure.

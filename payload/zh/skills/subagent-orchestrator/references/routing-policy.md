# 路由策略

使用能够完成验收锚点的最小路由。每个子代理都必须是叶子，主代理是唯一的协调者和决策负责人。每次生成都显式设置非 `default` 的 `agent_type`。不得路由到内置 `default`；无法匹配的工作留在主代理。

## 准入角色

| 需求 | 路由 | 仅在以下条件满足时准入 |
| --- | --- | --- |
| 一个狭窄的只读代码库问题 | 内置 `explorer` | 聚焦扫描能够替代主代理的实质探索 |
| 一个策略已确定的实现切片 | 内置 `worker` | 策略、准确所有权和验收标准均已确定 |
| 结构化测试或有界日志证据 | `evidence_tester` | 一个噪声较大的证据面能够按准确验收字段和一个 artifact 隔离 |
| 一个未解决的执行、状态或持久化边界 | `boundary_mapper` | 主代理的定向检查不足，且不要求设计结论 |
| 一个独立的高风险不变量 | 新鲜的 `risk_reviewer` | 写入者已终止、候选状态已冻结且不变量准确 |
| 一个有证据支持的不可逆歧义 | `risk_reviewer_max` | 有效的审查升级已写明竞争性解释和受影响决策 |
| 简单、需要策略判断、含糊、有顺序或共享状态的工作 | 主代理 | 委派会增加协调成本，或过早拆分推理 |
| 通用或无法匹配的回退 | 主代理，不生成子代理 | 永不调用内置 `default`；选择专用角色或直接完成 |

不要替换角色。`evidence_tester` 收集证据，不修改源代码或作无依据诊断；`boundary_mapper` 追踪一个边界，不作设计结论；审查者只证伪命名不变量，不广泛探索、不实施、不发明需求，也不拥有修复权。

## 遵循有效转换

- 将 `explorer` 和 `boundary_mapper` 的证据返回主代理。只有主代理确定策略后，才能分配 `worker`。
- 仅当原始测试或日志量会污染主代理上下文时使用 `evidence_tester`；普通的定向检查留在主代理。
- 审查前必须取得 `worker` 的终态收据、主代理抽样、整合和直接检查。不得审查仍在变化的候选状态。
- 将审查返回的 BLOCK 交由主代理独立裁决。不得把设计所有权转给审查者，也不得自动授权 `worker`。
- 仅从经有效审查确认的不确定结果路由到 `risk_reviewer_max`。PASS、BLOCK、证据缺失或普通不确定性都不得触发它。

## 约束拓扑与扩展

- 允许委派时先启动一个子代理。只有任务有界、独立、所有权安全，并预期减少耗时或降低上下文中的噪声时，才增加普通首轮的第二个子代理。普通上限为两个子代理和一个活动写入者，写入范围不得重叠。
- 禁止子代理继续委派和跨子代理协作。扩展检查点不得放宽叶子拓扑、所有权、写入范围或新鲜度规则。
- 后续波次、增加写入者、扩大范围或重新运行审查时打开扩展检查点。先收集并整合当前必需的收据；只有新证据、实质范围与风险未变，且被替代的工作所带来的收益足以抵消协调成本时，主代理才解除检查点并允许启动一个有界的下一个子代理，否则继续直接完成。
- 用户要求检查点或触及实质性用户级边界时才询问。扩展本身不是问题。如果相关选择会改变结果、验收、外部行为、兼容性、安全、隐私、架构、重要成本、迁移或不可逆影响，应尽早询问并推荐默认选项。报告操作阻塞，不把它们伪装成选项。
- 操作叶子和新鲜审查均使用各自声明的角色边界与隔离执行上下文。遭到拒绝或授权已过时时，在一次阻塞动作收据后结束叶子，并应用委派契约中的任务范围权限熔断机制。主代理的模型与推理设置由用户控制。使用英文收据和固定的子代理设置：内置角色为 Terra/max，`evidence_tester` 为 Luna/max，`boundary_mapper` 为 Terra/max，`risk_reviewer` 为 Sol/xhigh，`risk_reviewer_max` 为 Sol/max。
- `sandbox_mode` 是请求的配置而不是硬授权边界；父级覆盖可能改变实际行为。将父级权限与角色匹配，同时保留角色动作边界。

## 路由审查

- 准入独立审查时使用一个新鲜的 `risk_reviewer`。多重审查需用户明确要求：最多三个新鲜审查者、互不重叠的不变量、一个冻结候选状态；不得投票或举办设计工作坊。
- 修复并重新复核后仍为 BLOCK 时，交回主代理按第一性原理裁决。对无依据的发现予以驳回；对已确认的问题直接修复；对真实阻塞予以识别。为再次独立审查打开扩展检查点前，必须有变更后的候选状态或新的区分性证据。
- 两次面向决策的尝试后仍未改变的不确定性视为证据平台期。停止尝试其他变体，取得最小区分性观察；不得仅为追求更高置信度而增加子代理。

## 关闭任务

子代理终态、门禁或预算耗尽只关闭已移交的工作。以与主张匹配的证据关闭原始结果；在最小真实任务证明核心行为前，不要建设支撑机制。
